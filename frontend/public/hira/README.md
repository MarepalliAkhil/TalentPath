# HIRA character images

Drop optional WebP images here. Every file is optional: when a file is missing,
the app shows a clean "HI" initials avatar in the brand colours instead (never a
broken image).

| File | Used for |
| --- | --- |
| `hira.webp` | Default portrait (fallback for every pose) |
| `hira-welcome.webp` | Login briefing, scheduling-link page |
| `hira-explain.webp` | HIRA activity page header |
| `hira-attention.webp` | Login briefing when something needs you |
| `hira-celebrate.webp` | Reserved (offer accepted, week 3B) |
| `hira-thinking.webp` | Reserved (while HIRA is working) |

Square images, at least 256 x 256 px, under 60 KB each. See docs/HIRA.md.
